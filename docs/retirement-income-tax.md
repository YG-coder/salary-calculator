## 지원 범위

2026년 마지막 근무일(근로관계가 유지된 마지막 날)에 퇴직하는 거주자 일반 근로자의 단일 퇴직만 지원한다. 중간정산·이전 퇴직소득 합산·근속기간 제외/가산·임원·비거주자·공적연금·명예퇴직 등 특례 및 세액공제/감면은 미지원이다. 이 조건은 사용자가 직접 확인한다. 기존 누적 지급액·기납부세액은 입력받지 않는 단건 경로이므로 결과에 **기존 누적 0원 가정**을 표시한다.

현금 일시금은 해당 지급이 가능한 경우의 예상액이다. 현금 수령 자격이나 IRP 이전 의무를 판정하지 않는다. IRP는 퇴직 시 전액을 직접 이전하고 비과세 퇴직소득이 없는 경우만 지원한다. 비과세 금액이 섞인 이전, 일부 이전, 수령 후 60일 내 재입금·환급, 이후 연금/연금외 인출은 미지원이다. 미지원은 세금 0원이 아닌 금액 없는 계산 보류다.

2026년 외 퇴직일은 보류한다. 기준연도만 변경한 배포는 정책 검사로 막는다. 정책 검사 통과 자체가 법령 변경 조사를 대신하지 않는다.

## 구현과 독립 검증값

`src/lib/retirementTax.ts`는 기존 `calculateSeverancePay`와 분리한다. 순서는 비과세 제외 → 소득금액 한도로 근속연수공제 → 환산급여 → 환산급여공제 → 기본세율 → 근속연수/12 → 지급 방식별 처리다. 각 단계의 금액 연산은 정수 분수로 하여 이진 소수 오차를 피한다. 안전한 정수 범위를 넘는 입력은 보류한다.

세법상 기간은 노동법 계산용 퇴직일(마지막 근무일 다음 날)을 사용하지 않는다. 2025-10-14~2026-10-13은 1년, ~2026-10-14는 2년이다. 2023-03-01~2024-02-29는 366일이어도 1년이며 2024-02-29~2025-02-28도 1년이다. 기간 제외·가산이 있으면 이 단순 산식을 적용하지 않는다.

국세청 원래 예제의 기간은 2004-01-01~2023-12-31이다. 테스트는 동일한 20년·금액을 유지하고 2007-01-01~2026-12-31로 이동했다. 공식 사이트가 이 2026년 날짜로 직접 조회한 결과라는 뜻은 아니다. 지방세·실수령액은 공식 소득세에 법정 징수 규칙을 적용해 별도로 산출했다.

7년 사례의 중간값: 근속공제 9,000,000원 → 환산급여 70,285,925원 → 환산급여공제 45,357,258원 → 과표 24,928,667원 → 환산산출세액 2,479,300원 → 산출세액 1,446,258원. IRP 전액 직접 이전이면 계좌 입금액은 50,000,123원, 이연 소득세 1,446,258원·이연 지방소득세 144,625원으로 표시한다. 현금 징수액과 일부 끝수가 다른 것은 의도된 구분이다.

공제 경계 5/10/20년, 환산급여 800만/7천만/1억/3억원, 기본세율 과세표준 전 구간의 전후를 검사한다. 경계 기대값은 구현을 호출해서 복사하지 않았다. 별도 Python Fraction으로 각 구간 폭에 해당 공제율/한계세율을 곱해 합산하고 정수 절사해 고정했으며, 근속 12년·공제 2천만원(환산배율 1)으로 입력을 구성했다. 고정값 테스트는 변경된 구현이 스스로 만든 정답과 비교하지 않는다.

화면 검사에는 초기 빈칸·미선택, 현금/IRP 전환, 특례 및 비과세 IRP 보류, 소액부징수 안내 초기화, 입력별 이전 결과 숨김, 버튼 선택 상태와 표시 문자열을 포함한다. 부모 퇴직금 결과에 계산 당시 입력만 연결하고, 부모 결과가 숨겨지면 세금 입력·결과도 함께 사라진다.
