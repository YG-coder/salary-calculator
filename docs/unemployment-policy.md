## 공식 근거

2026-11-17에 다음 자료를 AI가 읽었다. 적용 대상은 일반 근로자의 구직급여 예상액이다. 일용근로자·예술인·노무제공자·자영업자 및 특수 경과조치는 계산 대상에 포함하지 않는다.

1. [현행 고용보험법 시행령](https://www.law.go.kr/LSW/lsInfoR.do?chrClsCd=010202&efYd=20260918&lsiSeq=288717): 제68조의 급여기초 임금일액 상한 113,500원에 60%를 적용해 일 상한 68,100원. 2025-12-23 개정 부칙 제1조는 2026-01-01 시행, 제4조는 시행 전 이직자에 종전 규정을 적용한다. 따라서 적용 구분은 신청일·지급일이 아닌 이직일이다. 이번 지원 구간은 2026-01-01~12-31로 한정한다. 2025년 이전은 미지원 안내한다.
2. [법제처 구직급여 수급액 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=3&cnpClsNo=2&csmSeq=722): 최저기초일액은 이직일 당시 시간급 최저임금과 이직 전 1일 소정근로시간을 기준으로 한다. 월평균임금÷30은 기존 간편 추정 경로이며 법정 평균임금의 정확한 산정을 대체하지 않는다. 통상임금 우선 적용, 산정 제외기간, 이전 수급 이력·가입기간 합산 등은 이번 범위에서 새로 구현하지 않았다.
3. [고용노동부 2026-09-14 상담 안내](https://1350.moel.go.kr/rtmview.do?id=1000320790): 2026년 이직자의 1~8시간 하한 8,256 / 16,512 / 24,768 / 33,024 / 41,280 / 49,536 / 57,792 / 66,048원과 68,100원 상한을 독립 기대값으로 대조했다. 개별 수급권 확정 자료가 아닌 일반 제도 안내다.
4. [고용보험법 시행규칙 제91조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lspttninfSeq=106145): 일·주·월·매주 변동 근로시간에 따라 평균 소정근로시간 산정 방식이 다르다. 주·월 단위는 유급휴일 시간을 포함한다. 화면은 이직확인서나 고용센터에서 확인한 1일 평균 소정근로시간을 받으며, 주간 시간만 임의로 5일로 나누지 않는다. 해당 시간 자체를 모르면 입력을 비워 두어 계산을 보류한다.
5. [급여기초임금일액 산정규정 제3조, 예규 제221호](https://law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000232090): 산정된 소수 시간은 올림, 8시간 이상은 8시간 적용. 2023-12-01 이후 이직자 규칙이며, 이전 수급자에 관한 경과조치는 2026년 이직만 지원하는 이번 경로에 적용하지 않는다. 1~3시간을 4시간으로 올리는 과거 규칙을 사용하지 않는다.
6. [고용노동부 공고 제2026-446호](https://www.moel.go.kr/info/lawinfo/lawmaking/view.do?bbs_seq=20260900700), [법제처 입법예고 본문](https://www.moleg.go.kr/lawinfo/makingInfo.mo?cptOfiOrgCd=&currentPage=3&edYdFmt=&keyField=&keyWord=&lawCd=2000000331346&lawSeq=88794&lawType=TYPE5&lsClsCd=&mid=&pageCnt=20&stYdFmt=): 상한을 하한과 연동하도록 바꾸는 입법예고를 확인했다. 최종 공포·2027년 적용 상한을 확인하지 못했다. '법적으로 상한이 존재하지 않는다' 또는 '미공포가 확정됐다'고 단정하지 않는다. 제품은 2027년 이직자 전부에 '상한 확정 여부 미확인'을 표시하고 계산하지 않는다. 최저임금만 올려 임의 상한을 만드는 Math.max 처리를 삭제했다.

## 검증과 제한

- 2026-12-31은 2026년 기준으로 계산, 2027-01-01은 보류한다. 날짜는 엄격한 YYYY-MM-DD 달력 날짜로 비교하고 상실일로 바꾸기 위해 하루를 더하지 않는다.
- 4시간·일평균임금 100,000원·가입 24개월·50세 미만: 하한 33,024원 < 60,000원 < 상한 68,100원, 150일 예상 합계 9,000,000원. 8시간 동일 조건은 하한 66,048원, 합계 9,907,200원. 수기 산출 기대값이다.
- 소수점 올림·8시간 제한 후 하한을 구하고, 평균임금의 60%에 상·하한을 적용한다. 단시간 근로자라는 이유로 상한 자체를 시간 비례 감액하지 않는다.
- 일평균임금 0/음수/소수 원/비정상 수, 잘못된 달력 날짜, 미지원 연도, 비정상 시간은 거부한다. UI 시간 입력에 지수 표기·빈칸을 0이나 기본 8시간으로 바꾸지 않는다.
- 가입 6개월 미만은 기존 추정 범위 밖으로 보류한다. 6개월 이상도 실제 수급 자격을 판정하지 않는다. 화면에 자격 충족 가정을 명시하고 함수의 isEligible 반환을 제거했다.
- 빌드 설정은 TAX_YEAR의 연초·연말에 실업급여 자료가 존재하고 상한이 8시간 하한 이상인지 검사한다. TAX_YEAR만 2027로 올리면 빌드가 실패한다. 온라인으로 법령 변경을 자동 탐지하는 기능은 아니다.
- 이직일·시간·나이·장애 여부 변경 시 이전 결과를 숨김. 2027년 보류에서 2026년으로 입력을 바꾸면 이전 보류 안내를 숨김. 이전 입력과 완전히 같은 값으로 되돌리면 기존 공통 hook 특성상 그 값의 스냅샷이 다시 표시될 수 있다.
- 브라우저 실기기 조작은 미실시이며 입력 전이는 React 렌더 회귀 검사로 확인한다.
