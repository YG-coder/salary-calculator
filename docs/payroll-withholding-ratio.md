## 공식 근거와 적용 범위

- [소득세법 시행령 제194조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsId=003956&lsJoLnkSeq=1000317984&print=print): 열람본 시행 2026-10-01. 근로자가 신청하는 80%·120%, 미선택 100%. 신청서 제출일 이후 지급분부터 해당 과세기간 종료일까지 적용. 화면 선택은 예상액 비교이며 회사에 신청서를 제출하지 않는다. 종된 근무지 제2항 특례는 지원하지 않는다.
- [국세청 근로소득 원천징수방법](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7862&mi=6426): 과세 월급 350만원, 가족 4명, 자녀 2명 예제는 49,340 − 29,160 = 20,180원, 80% 16,140원, 120% 24,210원이다. 자녀공제 후 비율 적용 및 10원 미만 절사 순서를 직접 확인했다. 이 페이지는 **개정 전 자녀공제액**을 사용하므로 현행 금액 근거로 쓰지 않는다.
- [별표 2, 2026-02-27 개정](https://www.law.go.kr/LSW/flDownload.do?flSeq=164357181&bylClsCd=110201): 공제대상가족 중 8~20세 자녀 1명 20,830원, 2명 45,830원, 추가 1명당 33,330원. 기존 코드의 2026-03-01 시행 구분을 유지. 본 계산기 기본 기준일은 2026-12-31이므로 새 공제액 적용. 동일 예제는 3,510원에서 80% 2,800원, 120% 4,210원(수기 계산).
- [국고금 관리법 제47조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1031453583): 시행 2026-01-02 열람본, 수입·지출 10원 미만 끝수 처리. 시행령 제109조의2의 분할 수납 등 예외는 이 월 급여 예상 계산 범위 밖이다.
- [지방세법 제103조의13](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000226371): 시행 2026-01-01 열람본, 거주자의 원천징수 소득세 10%를 특별징수. 선택 비율 적용 후의 소득세로 지방소득세를 계산한다.
- [지방회계법 제55조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0055&lsiSeq=276363&urlMode=lsScJoRltInfoR): 시행 2026-01-02 열람본, 10원 미만 끝수 생략 가능. 기존 지방소득세 10원 미만 절사 유지. 분할 징수 예외는 미지원.

일반 거주자 월 급여 예상 원천징수용이다. 비거주자, 종된 근무지, 특례 감면, 학자금 별도 처리, 상여 정산, 연말정산 최종세액은 이번 기능으로 지원하지 않는다. 80% 선택은 최종 세금을 줄이는 기능이 아니다.

## 홈택스 실제 조회 (2026-11-17, AI 브라우저 확인)

[홈택스](https://www.hometax.go.kr/) → 검색 “근로소득 간이세액표” → 세금신고 > 원천세 신고 > 근로소득 간이세액표. 화면이 2026-03-01 시행임을 확인했다. 개인 정보 없이 가상 입력을 조회했다.

| 과세 월급 / 가족 / 해당 자녀 | 선택 | 소득세 | 지방소득세 |
| --- | --- | --- | --- |
| 3,500,000 / 4 / 2 | 80% | 2,800 | 280 |
| 동일 | 100% | 3,510 | 350 |
| 동일 | 120% | 4,210 | 420 |
| 10,000,029 / 1 / 0 | 80% | 1,225,920 | 122,590 |
| 동일 | 100% | 1,532,400 | 153,240 |
| 동일 | 120% | 1,838,880 | 183,880 |

두 번째 사례는 고소득 산식 1,507,400 + 25,000 + 29 × 0.98 × 0.35 = 1,532,409.947원. 홈택스는 이를 1,532,400원으로 절사한 뒤 비율을 적용한다. 120%에서 끝에 한 번만 절사한 1,838,890원과 구분된다. 기존 고소득 산식 절사를 유지하고, 자녀공제 후 0원 하한을 적용한 세액에 선택 비율과 최종 10원 절사를 적용했다. 지방소득세는 그렇게 확정된 소득세의 10%에서 10원 미만 절사한다.

직접 조회한 범위는 위 두 입력이다. 다른 경계는 공식 표·산식의 독립 수기 기대값으로 검증하며 홈택스 전수 조회로 표현하지 않는다.

## 검증 기록

- 로컬 검사: `npm test` 통과. 이후 추가한 자녀공제·0원·고소득 렌더 검사는 `npx vitest run src/lib/__tests__/payrollWithholding.test.ts`로 통과 확인. 최종 `npm run typecheck`, `npm run lint`, `git diff --check` 통과.
- 검증 내용: 개정 전 국세청 예제, 현행 홈택스 두 입력, 공식 표 경계 수기 기대값, 잘못된 비율 거절, 0원 하한, 가족 11명 초과, 100% 기존 고정값 유지, 4대보험 불변, 빈 금액 보류, 비율 변경 시 이전 결과 숨김, 토글 선택 상태와 결과별 사용자 문구.
- 기본 빌드: `npm run build`는 Turbopack의 프로세스 생성·포트 바인딩 `Operation not permitted`로 실패. 권한을 높인 재실행도 같은 제한으로 실패했으며 기본 빌드 통과로 기록하지 않는다.
- 대체 빌드: `npx next build --webpack` 및 `node scripts/check-site-urls.mjs` 통과. 생성 결과의 정본 주소·OG/Twitter 이미지·카드·사이트맵·robots·JSON-LD·이미지 자산 검증 포함. 기본 빌드 실패를 대체 빌드 결과로 숨기지 않는다.
- 커밋: 이 문서·코드·테스트를 함께 로컬 커밋한다. 생성 파일은 제외한다.
- 푸시·배포·운영 화면 확인: 미실시. 이 기능의 실제 브라우저 조작은 미실시이며 로컬 렌더 테스트로 확인했다. 홈택스 공식 조회 화면은 위에 적은 범위만 직접 조작했다.
